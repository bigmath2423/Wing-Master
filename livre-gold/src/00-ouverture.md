# Avant d'ouvrir le manuel {: .libre }

## Comment utiliser ce manuel {: .libre }

*Un outil de travail. Pas un livre à lire une fois.*

Vous savez lire un graphique. Vous savez marquer une structure, repérer une
liquidité, exécuter proprement.

Il vous manque une seule chose : **savoir dans quel sens chercher.**

C'est le seul objet de ce manuel.

::: cle
La macro ne vous dira jamais quand entrer.
Elle vous dira dans quel sens vous avez le droit de chercher.
:::

### Les trois usages

::: cartes
- **Chaque matin — 10 min** Partie 5, la routine. Vous obtenez un biais écrit en trois lignes avant l'ouverture de Londres.
- **Avant une publication — 30 s** Partie 2, la fiche de l'indicateur. Vous savez ce qui fait monter ou baisser l'or.
- **Le dimanche — 20 min** Parties 3, 4 et 6. Vous fixez le régime de la semaine et le scénario dominant.
:::

### Ce que vous ne trouverez pas ici

- Aucune base de trading. Vous les avez déjà.
- Aucun signal d'achat ou de vente.
- Aucune théorie économique sans application directe sur XAUUSD.

### Chaque concept, trois niveaux

Les notions importantes sont toujours expliquées ainsi :

::: niveaux
- **Simple** En une phrase, sans jargon. Ce que vous diriez à quelqu'un qui n'y connaît rien.
- **Professionnel** Le mécanisme exact, avec le vocabulaire du marché.
- **Sur le Gold** Ce que vous en faites concrètement dans votre biais du jour.
:::

### Une seule chose à retenir avant de commencer

L'or ne verse aucun intérêt. Le détenir a donc un coût : le rendement auquel
vous renoncez ailleurs.

Ce coût porte un nom. **Le taux réel.**

::: cle
Taux réels en baisse → l'or monte.
Taux réels en hausse → l'or baisse.
Tout le reste de ce manuel explique ce qui fait bouger les taux réels.
:::

### Avertissement

Manuel pédagogique. Ne constitue pas un conseil en investissement, ne promet
aucun résultat.

Les chiffres et niveaux cités en exemple illustrent des **mécanismes** : ce sont
des séquences typiques, pas un relevé historique. Les données réelles se
vérifient sur les sources officielles listées en fin de manuel.
