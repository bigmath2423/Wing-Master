START

Demarrage rapide

  • Graphique : XAUUSD (or), unite de temps M15 (execution) avec contexte H1. M5 possible pour les entrees fines.
  • Installation : Pine Editor → coller le code → Ajouter au graphique. Apres chaque mise a jour : supprimer l'ancienne version du graphique puis re-ajouter (sinon TradingView garde les anciens reglages).
  • Alerte : Alt+A → condition = l'indicateur → « Tout appel de fonction alert() » → Une fois par barre a la cloture. Seuls les signaux ≥ 85 (A+/A) declenchent une alerte.

  • Distance M11 : 0.5 ATR
💡 La regle d'or du calibrage

Choisissez UN profil, tradez-le 2 semaines en demo sans rien toucher, notez vos resultats, puis ajustez un seul parametre a la fois. C'est exactement ainsi qu'un desk professionnel calibre un systeme. Le sur-reglage permanent est l'ennemi n°1 de la constance.

Defauts parfaits

Entree au niveau institutionnel exact + SL derriere la vraie invalidation.

ParametreValeurPourquoi
Entree & Stop Loss de precisionONEntree limite sur bord d'OB / milieu de FVG, SL structurel serre, meilleur R:R

Marge du SL structurel (x ATR)0.5Marge serree derriere l'invalidation reelle
⚠️ Trade-off assume

Avec une entree limite, le prix peut parfois ne pas revenir remplir l'ordre : on rate le trade. C'est le prix de la precision (meilleures entrees, R:R superieur). Si tu preferes ne jamais rater un signal : OFF = comportement d'origine exact (entree au prix de cloture).

💡 Lire les deux types de zones

Contour PLEIN = zone predictive proche (Module 10). Contour POINTILLE = zone d'anticipation lointaine (Module 11). Vert = achat, rouge = vente. • ACTIVE quand le prix est dedans - mais c'est TOUJOURS le score /100 et les deux verrous qui valident ou refusent le trade.
